# Portfólio — Bruno Chacon

Meu portfólio pessoal de desenvolvedor web freelancer, feito com **HTML, CSS e JavaScript puro**, sem frameworks e sem bibliotecas.

O site apresenta meus projetos reais para clientes, minha formação e as formas de entrar em contato.

## Seções

- **Início**: apresentação e chamadas para ação
- **Projetos**: portfólio fotográfico da Zoza, Buzzi Store e Loja de Bairro
- **Sobre**: formação e tecnologias
- **Contato**: e-mail, WhatsApp e GitHub

## Recursos

- Design responsivo (celular primeiro)
- Menu mobile em tela cheia
- Cabeçalho que muda ao rolar a página
- Animações de entrada ao rolar (Intersection Observer)
- Efeito parallax leve no topo
- Letreiro animado (marquee) com os serviços
- Suporte a `prefers-reduced-motion` para quem prefere menos movimento
- Fontes Playfair Display e Poppins (Google Fonts)

## Tecnologias

- HTML5
- CSS3 (variáveis, Grid, Flexbox, animações)
- JavaScript (ES6+)

1. Clone o repositório:

   ```

   ```

2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server do VS Code).
